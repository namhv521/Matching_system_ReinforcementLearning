## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/<your-username>/susois.git
cd susois

# Create virtual environment (using uv)
uv venv
.venv\Scripts\activate   # Windows

# Install dependencies
uv sync

# Copy env file
copy .env.example .env
```
